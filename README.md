# ÉVORA

Protótipo jogável de evolução automática através de eras.

## Publicar com GitHub Pages
1. Abra **Settings** deste repositório.
2. Entre em **Pages** no menu lateral.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/ (root)**.
5. Clique em **Save** e aguarde a publicação.

Endereço esperado: https://guto157.github.io/evora-game/

## Protótipo atual
- Corrida automática, sem controles durante a jornada.
- Recompensas e melhorias permanentes.
- Progresso salvo no armazenamento local do navegador.
- Cinco ambientes visuais em progressão por eras.

Esta é a primeira versão jogável. Personagem, cenários, efeitos e sistemas de evolução serão refinados nas próximas etapas.
